# Heart Disease Data Analysis

Проект по анализу факторов риска сердечно-сосудистых заболеваний на основе открытого датасета Heart Disease UCI.

## 🛠 Стек технологий
- **Python** (pandas, numpy, matplotlib, seaborn)
- **PostgreSQL** (SQLAlchemy для подключения)
- **Jupyter Notebook** в VS Code

## 📊 Что было сделано
1. **Очистка данных**: удалено 723 дубликата, осталось 302 уникальные записи.
2. **Кодировка**: текстовые признаки переведены в числовые.
3. **Обнаружение аномалии**: найдена и исправлена инверсия целевой переменной (`target`).
4. **SQL-анализ**: написано 6 запросов (JOIN, CTE, оконные функции).
5. **Статистика и визуализация**: построены корреляции, таблицы сопряжённости и 7 графиков.

## 📁 Структура проекта
- `data/` — исходный датасет
- `notebooks/` — Jupyter Notebook с анализом
- `sql/` — SQL-запросы
- `figures/` — графики

## 🚀 Как запустить
1. Установить зависимости: `pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary python-dotenv`
2. Создать базу данных `heart_db` в PostgreSQL.
3. Создать файл `.env` с параметрами подключения.
4. Открыть и запустить `notebooks/analysis.ipynb`.
